## What I Learned

**Lesson 6.1 - Git Basics:** Learned conventional commits (Style, Fix, Docs), viewing history with `git log --oneline --graph`, and documenting changes.

**Lesson 6.2 - Branching & Merging:** Created feature branches, simulated conflict in about.html from two branches, resolved conflict using `<<<<<<< HEAD` markers, and merged with `Fix: resolve merge conflict in about.html`.

**Lesson 6.3 - GitHub Remote:** Practiced `git remote -v`, `git push -u origin main`, collaboration simulation by cloning to week03-clone, making changes, pushing, and pulling back. Created .gitignore for node_modules/, .vscode/, .DS_Store, and temp files.

**Lesson 6.4 - Professional README:** Replaced template with real project info, live demo link, and accurate project structure.
